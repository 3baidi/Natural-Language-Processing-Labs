# Lab 2: Text Pre-processing and Regular Expressions

## Overview
This folder contains the solution for NLP Lab 2. The objective was to practice text cleaning, pattern matching with regular expressions, and word tokenization.

## Tasks Completed
1. **Hashtag Extraction:** Used `re.findall()` and `collections.Counter` to extract and rank the top 10 hashtags from a Twitter sentiment dataset.
2. **Regex Compilation:** Used `re.compile()` and `pattern.sub()` for efficient text substitution.
3. **Regex Splitting:** Used `re.split()` to divide text based on numeric patterns.
4. **Tokenization:** Compared word tokenization outputs between `spaCy` and `NLTK`.
