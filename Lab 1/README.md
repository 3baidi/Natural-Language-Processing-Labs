# Lab 1: Introduction to Natural Language Processing

## Overview
This folder contains the solution for NLP Lab 1. The objective of this exercise is to select, load, and perform initial exploration on a text-based dataset.

## Dataset Details
* **Dataset:** IMDB Dataset of 50K Movie Reviews
* **Format:** CSV
* **Attributes:** `review` (text), `sentiment` (positive/negative)

## Tasks Completed
1. **Dataset Selection:** Sourced a CSV text dataset suitable for NLP.
2. **Data Loading:** Read the local CSV file into a Pandas DataFrame.
3. **Data Exploration:** Generated descriptive statistics, checked data types and null values, and calculated the class distribution of the sentiments.
